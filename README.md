# Yed38.github.io

Personal research portfolio for Yunus Emre Dursun. The site is intentionally static, responsive, and ready for GitHub Pages.

The portfolio includes an interactive encoder–decoder Transformer explainer. Visitors can step through tokenization, encoder self-attention, contextual memory, masked decoder attention, cross-attention, and next-token prediction. The connection strengths are explicitly labeled as illustrative so the visual teaches the mechanism without pretending to expose a trained model’s internal measurements. It runs entirely in the browser and requires no backend.

## Profile photo

For a permanent public photo, add a square or portrait image at `assets/profile.jpg`. The **Add your photo** button on the page is only a browser-local preview; GitHub Pages cannot write uploaded files back to the repository.

## Publish on GitHub Pages

1. Create a public repository named `Yed38.github.io` on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site will be available at `https://yed38.github.io/` after GitHub finishes the deployment.
